# Moderator guide (internal)

For GMOOCA staff and volunteer moderators. Members see the public version in [rules.md](rules.md), Part 5.

## Principles
- **Be consistent.** The same violation gets the same response, whoever posted it.
- **Act fast on legal risk; take your time on everything else.** Security bypasses, piracy, doxxing, threats, scams and illegal content come down immediately. Tone problems get a private note first.
- **Remove, don't rewrite.** Don't edit a member's infringing or illegal post into something acceptable. Remove it, then tell the member why. Editing can make GMOOCA responsible for the content.
- **Moderate in private.** Use private messages and warnings, not public call-outs.
- **Log everything.** Every action gets a reason in the moderator log.
- **Never give legal advice** in a moderator capacity, even "it's legal in my state."

## Quick reference

| You see | Do |
|---|---|
| Post in the wrong section, duplicate thread | Move or merge; note to member |
| Missing details in a help request | Reply with the "How to ask for help" template |
| AI-written post with no tag | Ask the member to add an "AI-assisted" label or tag; no points. Repeated or mass-produced: treat as spam |
| Mild incivility | Private note; edit only to remove an insult if the post is otherwise useful |
| Harassment, slurs, threats | Remove; warning or suspension. **Threats of violence:** screenshot, preserve, escalate to an admin at once |
| Personal information (doxxing) | Remove immediately; suspend; preserve a copy in the moderator log |
| Request for or link to a manual, firmware, ROM or CF image, or PAR sheet | Remove the file or link; reply pointing to legitimate sources; warning on a repeat |
| Security bypass or cheating content | Remove; warning minimum, ban if it's instructional or for sale |
| Gambling promotion or affiliate links | Remove; ban spam accounts |
| Undisclosed commercial promotion | Remove; note to member about the disclosure rule |
| Marketplace scam report | Hide the listing; freeze the account pending review; tell the reporter what we did (not the details); escalate |
| Suspected stolen machine (removed plates, casino asset tags) | Hide the listing; escalate to an admin; don't accuse publicly |
| DMCA notice received at dmca@ | Admin only: check it's complete (6 elements), remove the material, notify the member, log a "Copyright" warning, file the notice |
| Subpoena, law-enforcement or preservation request | Admin only: don't respond; forward to compliance@ and the attorney; preserve the data |
| Member says they're under 18 | Suspend the account; admin closes it and deletes personal data |
| Self-harm or crisis content | Don't debate it. Reply privately with crisis resources (call or text 988 in the U.S.), notify an admin, remove the content if public |

## Warning points (Invision)

| Reason | Points | Expires |
|---|---|---|
| Off-topic or wrong section (repeat) | 1 | 6 months |
| Incivility | 1 | 6 months |
| Unapproved promotion or spam (human) | 2 | 6 months |
| Copyright | 2 (counts as a strike) | 12 months |
| Harassment | 3 | 12 months |
| Security bypass or cheating content | 3 | Never |
| Doxxing | 5 | Never |
| Scam or fraud | Ban | — |
| Spam bot | Ban, then delete content | — |

Automatic actions: **3 points** puts new posts under moderation for 30 days, **5 points** suspends for 14 days, **8 points** sends the case to an admin to decide on a ban. **3 Copyright strikes in 12 months closes the account** (the repeat-infringer policy).

## Appeals
A different staff member from the one who acted reviews it. Reply within 14 days and log the outcome. An overturned action gets its warning points removed.

## Records
Keep the moderator log, warnings, DMCA notices and counter-notices, and legal requests for at least **5 years**. Don't delete logs to tidy up.
